# Evidence Model

Every material H.U.G.S. finding should support:

CLAIM -> CONTROL -> EVIDENCE -> RESPONSIBLE AUTHORITY -> PATIENT CONSEQUENCE -> REMEDIATION -> VERIFICATION

Evidence classes:

E0 - Unsupported allegation  
E1 - Patient / witness statement  
E2 - Internal record or correspondence  
E3 - Clinical or billing record  
E4 - Institutional policy / contract / formal procedure  
E5 - Regulator / court / accreditation / government record  
E6 - Independently reproduced multi-source evidence

Evidence confidence should be recorded separately from severity.
